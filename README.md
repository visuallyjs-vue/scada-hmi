## HMI ISA-101 Standard

The design of this app is in accordance with the HMI ISA-101 standard

https://hmilibrary.com/standards/isa-101

### Color usage

- Grayscale is the Normal State: Static equipment, piping, and processes in a normal, healthy state should be represented in shades of gray. This creates a calm, non-distracting background, making abnormal situations stand out. We use #A9A9A9 for the normal state color.
- Color for Abnormal States: Color should be used exclusively to draw the operator's attention to abnormal or alarm conditions. This ensures that when a color does appear, it is immediately recognized as something that requires attention.
- Consistent and Standardized Meanings: Colors should have a consistent and predefined meaning across all HMI screens. An operator shouldn't have to guess what a color means.
